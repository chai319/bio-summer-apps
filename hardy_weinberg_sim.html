問題 5. 集団遺伝学と遺伝子頻度

日本の里山には雌の前翅に4種類の表現型が存在するミドリシジミが棲息している。 表現型の遺伝は常染色体上の A, B, O の3つの複対立遺伝子による。 遺伝子 A と B に優劣関係はなく（共優性）、どちらも O に対して優性である（A = B > O）。

• 対立遺伝子頻度: A → p,   B → q,   O → r   (p + q + r = 1)
• 100個体の調査結果: 無紋型 25個体 (0.25), 赤斑型 39個体 (0.39), 青斑型 24個体 (0.24), 赤斑・青斑型 12個体 (0.12)

解法の極意: 二項展開の平方根を利用した補集合テクニック

通常、p + q + r = 1 より p = 1 - (q + r) です。
ここで、青斑型 (\(q^2 + 2qr\)) と 無紋型 (\(r^2\)) の頻度を足し合わせると：

\( \text{青斑型} + \text{無紋型} = (q^2 + 2qr) + r^2 = (q + r)^2 \)

両辺の平方根をとると： \( \sqrt{\text{青斑型} + \text{無紋型}} = q + r \)
これを \( p = 1 - (q + r) \) に代入すると、\( p = 1 - \sqrt{\text{青斑型} + \text{無紋型}} \) という解法公式が得られます！

本問題の具体的な計算手順

STEP 1: r を求める
劣性ホモ接合である無紋型 (OO) の頻度は \(r^2 = 0.25\)
平方根をとって：
r = √0.25 = 0.50
STEP 2: p を求める
青斑型 (0.24) と無紋型 (0.25) より：
\( p = 1 - \sqrt{0.24 + 0.25} = 1 - \sqrt{0.49} \)
p = 1 - 0.70 = 0.30
STEP 3: q を求める
赤斑型 (0.39) と無紋型 (0.25) より：
\( q = 1 - \sqrt{0.39 + 0.25} = 1 - \sqrt{0.64} \)
q = 1 - 0.80 = 0.20
(※ \( q = 1 - p - r = 1 - 0.30 - 0.50 = 0.20 \) でも可)

パラメータ調整

遺伝子 A 頻度 (p): 0.30
遺伝子 B 頻度 (q): 0.20
遺伝子 O 頻度 (r): 0.50
※ p + q + r = 1.00 になるよう自動調整されます。
