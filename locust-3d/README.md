# 🦗 トノサマバッタ 相変異 3D 比較解剖学 (Locust Phase Polymorphism 3D Explorer)

高等学校「生物」「生物基礎」の「相変異（Phase polymorphism）」を、iPadやPCのWebブラウザ上で360度インタラクティブに観察・比較・AR体験できるリアルタイム3D Webアプリケーションです。

---

## 🌟 主な特徴

### 1. 孤独相（Solitary）と群生相（Gregarious）の精緻な解剖学的3Dモデリング
- **翅の長さ（前翅・後翅）の違い**:
  - **孤独相**: 腹部末端とほぼ同じ長さ（約 39.0 mm）。
  - **群生相**: **腹部末端を大幅に超えて後方に長く伸張**（約 54.0 mm、長距離集団飛翔への適応進化）。
- **後肢（跳躍肢）の違い**:
  - **孤独相**: 大腿（腿節）が**非常に長くスラリ**としており、単発の強力な跳躍に特化（約 36.0 mm）。
  - **群生相**: 大腿が**相対的に短く頑丈**で、地上行進（マーチング）や飛翔時の空気抵抗軽減に適応（約 27.0 mm）。
- **形態指標「E/F比（Elytron length / Femur length比）」の逆転**:
  - 孤独相: **E/F ≒ 1.08**（翅が短く、足が長い）
  - 群生相: **E/F ≒ 2.00**（翅が長く、足が短い）
- **前胸背板（Pronotum）の形状変化**:
  - 孤独相: 前胸背板がやや長く、背中の中央稜線（キール）が**なだらかな凸型**。
  - 群生相: 前胸背板がやや短く、輪郭が**低く平たい**。
  - 教材モデルでは実物以上の角・帆状突起に見えないよう、差を控えめに表現。
- **体色と複眼のオミジウム模様**:
  - 孤独相: 草地に溶け込む鮮やかな草緑色（隠蔽色）。
  - 群生相: 暗褐色・黒斑・黄橙色が混じる警戒色。複眼には**明瞭な縦縞ストライプ模様**。

---

### 2. 生きているような待機アニメーション（Bio-mimetic Idle Animation）
昆虫特有の微細な生体運動をリアルタイムにシミュレート：
- **触角（Antennae）の探査微動**: 多節チェーンによる空気の流れを感じるしなり ＋ 数秒に1回の鋭いピクつき反射。
- **頭部・首関節のチルト**: ゆっくりとした呼吸ピッチと周囲を見回す首かしげ。
- **口器（小腮鬚 Maxillary palps）の触動**: 口元の感覚ヒゲが小刻みにピコピコ動く探査動作。
- **腹部の気管呼吸ポンピング（Respiration）**: 腹節がリズミカルに収縮・膨張する呼吸運動。
- **後肢の重心移動**: 微小な脚の微動。

---

### 3. 多彩な観察モード ＆ 計測ガイド
- **⚖️ 2頭並列比較モード**: 孤独相と群生相を左右に並べ、同じカメラ操作で同時にぐりぐり回して比較可能。
- **🌱 孤独相 / 🔥 群生相 単体モード**: それぞれの個体にクローズアップして細部を観察。
- **🧬 重ね合わせモード**: 2頭を同一点に配置し、半透明X線表示で形態・プロポーションの差を重ねて直感把握。
- **📏 3D計測ガイド**: 翅長（E）、後肢長（F）、腹部末端基準線、前胸背板形状を3D空間内に寸法線と数値で表示。
- **🔭 部位フォーカスボタン**: 全体 / 翅の長さ / 後肢 / 前胸背板 / 頭部・複眼 にワンタップで最適ズーム。

---

### 4. iPad / iOS Safari ネイティブ AR Quick Look 対応
- **「👓 AR表示 (Quick Look)」** ボタンを押すと、ブラウザ内で現在のバッタモデル（単体または並列セット）を即座に `.usdz` 形式に変換。
- iPad / iPhone の標準カメラが起動し、**目の前の机や床の上に等身大・拡大スケールでバッタが出現！** 
- 教室の机の上にバッタを置いて、周りを歩き回りながら観察できます（専用アプリのインストール不要）。

## 🚀 使い方・公開方法

### GitHub Pages で公開する場合（推奨）

1. 本リポジトリの全ファイルを GitHub に push します。
2. GitHub のリポジトリ画面で **Settings** > **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選択し、Branch を `main`（または `master`）、フォルダを `/ (root)` に設定して **Save** をクリックします。
4. 数十秒〜1分ほどで公開URL（例: `https://<username>.github.io/<repo-name>/`）が発行されます。
5. iPad の Safari でそのURLを開くだけで、インストール不要で全機能が快適に動きます！

### ローカル環境でテスト・起動する場合

Webサーバー（Python または Node.js）を起動してブラウザで開きます。

```bash
# Pythonの場合
python3 -m http.server 8000

# Node.js (npx) の場合
npx serve .
```

ブラウザで `http://localhost:8000` にアクセスしてください。

## 📱 iPadでの操作方法

- **1本指ドラッグ**: バッタを360度自由に回転
- **ピンチイン / ピンチアウト（2本指）**: 拡大・縮小（ズーム）
- **2本指ドラッグ**: 画面内の平行移動（パン）
- **「AR表示」タップ**: iPadのARカメラが起動し、現実空間にバッタを投影

## 🛠️ 技術スタック

- **3Dグラフィックス**: [Three.js](https://threejs.org/) (r160, ES Modules)
- **カメラ制御**: Three.js OrbitControls (iPadタッチジェスチャー最適化)
- **プロシージャルテクスチャ**: HTML5 Canvas 2D API (キチン質、複眼格子、翅脈網、筋肉山型斑)
- **AR機能**: Three.js USDZExporter + Apple AR Quick Look
- **UI / スタイリング**: Vanilla CSS (グラスモフィズム、レスポンシブ、ダークテーマ)
- **外部依存**: 完全ゼロ（CDN経由のThree.jsのみ。静的ホスティングで即座に動作）

## 📚 生物教育（教材としてのポイント）

- **単元**: 高等学校 生物基礎 / 生物「動物の行動と環境」「個体群の密度効果」
- **指導のねらい**:
  「同じ遺伝子を持つ同種でありながら、環境（生息密度刺激）に応じてこれほどまでに劇的に姿形・行動が変わるのはなぜか？」という問いを生み出し、適応進化の合理性（単独での天敵回避・跳躍特化 vs 群れでの大移動・長距離飛翔）を自ら発見・考察する探究学習に最適です。
